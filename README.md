# Titanic Survival Prediction ML

## Overview
A classic Titanic survival prediction notebook with preprocessing, model training, and accuracy evaluation.

## Problem Statement
Passenger survival prediction is a useful supervised-learning benchmark for tabular preprocessing and classification.

## Features
- Train/test CSV workflow
- Categorical encoding
- Multiple classifier baselines
- Submission file generation

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
- train.csv
- test.csv
- submission.csv

## Models / Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM

## Results
Notebook outputs include accuracy score lines such as 0.8101 and 0.8324 from sample runs.

## Project Structure
- notebooks/
  - titanic-survival-prediction.ipynb

## How to Run
- `pip install -r requirements.txt`
- `jupyter notebook notebooks/titanic-survival-prediction.ipynb`
